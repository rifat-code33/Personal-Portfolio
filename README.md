# Md. Rifatul Islam | Full-Stack Web Developer Portfolio 🚀

একটি মডার্ন, রেসপন্সিভ এবং আকর্ষণীয় পার্সোনাল পোর্টফোলিও ওয়েবসাইট, যা ফ্রন্টএন্ড এবং ফুল-স্ট্যাক ডেভেলপমেন্টে আমার দক্ষতা, স্কিল এবং প্রজেক্টসমূহ তুলে ধরার জন্য তৈরি করা হয়েছে।

🌐 **Live Demo:** https://personal-portfolio-theta-murex.vercel.app/

---

## 📸 প্রজেক্ট ওভারভিউ (Overview)
এই পোর্টফোলিও সাইটটিতে ইউজার-ফ্রেন্ডলি ইন্টারফেস, মডার্ন ডিজাইন এবং আকর্ষণীয় অ্যানিমেশন ব্যবহার করা হয়েছে। রিক্রুটার বা ভিজিটররা যাতে খুব সহজেই আমার ব্যাকগ্রাউন্ড, স্কিল এবং রিয়েল-ওয়ার্ল্ড প্রজেক্টগুলো দেখতে পারেন, সেভাবেই এটি ডিজাইন করা হয়েছে।

---

## ✨ মূল ফিচারসমূহ (Features)
* **মডার্ন ইউআই/ইউএক্স (Modern UI/UX):** ক্লিন এবং রেসপন্সিভ লেআউট যা যেকোনো ডিভাইসে (মোবাইল, ট্যাবলেট, ল্যাপটপ) সুন্দরভাবে কাজ করে।
* **প্রজেক্ট শোকেস:** আমার সেরা প্রজেক্টগুলোর (যেমন: Animated React Tailwind Portfolio, Brainwave Modern UI ইত্যাদি) ডিটেইলস ও লিংক।
* **স্কিল সেকশন:** টেকনিক্যাল স্কিল এবং প্রযুক্তির একটি সুসংগঠিত তালিকা।
* **কন্টাক্ট ইনফো:** সোশ্যাল মিডিয়া ও যোগাযোগের মাধ্যমগুলোর সহজ অ্যাক্সেস।

## 🛠️ ব্যবহৃত টেকনোলজি (Tech Stack)
এই প্রজেক্টটি তৈری ও ডিপলয় করতে নিচের প্রযুক্তিগুলো ব্যবহার করা হয়েছে:
* **Frontend:** React.js / Next.js, Tailwind CSS, HTML5, CSS3, JavaScript (TypeScript)
* **Version Control:** Git & GitHub
* **Deployment:** Vercel
